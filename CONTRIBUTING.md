# Contributing to xmcam-local

First off, thank you for considering contributing to `xmcam-local`! It's people like you that make open source such a great community.

## Where do I go from here?

If you've noticed a bug or have a feature request, make sure to check if there's already an issue for it. If not, open a new issue!

## Development

1. Fork the repo and create your branch from `main`.
2. Ensure you have Go 1.20+ installed.
3. Run `./extract_web_assets.sh` to get the necessary Web assets.
4. Make your changes in `main.go` or other relevant files.
5. Ensure the code compiles and runs successfully (`make build` / `make run`).

## Pull Requests

- Keep your PRs focused on a single issue or feature.
- Provide a clear and descriptive title.
- If your PR fixes an open issue, reference it in the description (e.g., "Fixes #1").
