## [0.1.0] - 2026-05-16
### Added
- Initial MVP release of `xmcam-local`.
- Go-based local proxy server mimicking `VideoPlayTool.exe`.
- Full HTTP and WebSocket (`/VideoPlay`) API bypass for XMEye cameras.
- Support for `DeviceCfg` and configuration pages.
- Helper script `extract_web_assets.sh` for downloading and extracting required Web UI files.
